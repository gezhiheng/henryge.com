## Why

博客目前只有动态点阵背景，视觉变化有限。增加与现有背景风格一致的浅色格子背景，并在每次完整刷新时随机选择一种背景，可以提升页面的变化感，同时保持站内阅读过程中的视觉稳定性。

## What Changes

- 为普通博客页面新增低对比度 CSS 格子背景。
- 在点阵背景和格子背景之间以 50/50 的概率随机选择背景。
- 每次完整刷新普通博客页面时重新选择背景；站内客户端路由跳转期间保持当前选择。
- 在首屏脚本阶段确定背景选择，避免水合或客户端加载后的背景闪烁。
- 保留现有点阵背景的动画、明暗主题适配和减少动画偏好行为。
- `/resume` 页面继续使用现有背景行为，不参与新的随机背景选择。

- `site-background`: 为普通站点页面提供点阵与格子背景的随机选择、页面生命周期保持和主题适配行为。

## Impact

- 影响根布局中的全局背景挂载和首屏初始化脚本。
- 影响 `DotsBackground` 组件，使其能够与 CSS 格子背景共享背景控制状态。
- 影响全局样式中的背景层级、格子绘制方式和明暗主题颜色。
- 需要继续识别并排除 `/resume`，不改变简历页面现有的背景和移动端处理。
- 不新增运行时依赖，不改变公开 API、内容数据或路由结构。
